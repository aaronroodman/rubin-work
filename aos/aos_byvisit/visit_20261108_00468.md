# MTAOS step for 20261108 seq 468

> **Status:** current · **Last updated:** 2026-11-10 · **Kind:** reference (visit report)

The large Tweak in effect during seq 468 came from the Optical Feedback Control (OFC)
step computed from seq 466. Seq 466 had wavefront measurements on only two of the four
corner wavefront sensors (CWFS), but the Main Telescope Active Optics System (MTAOS) did
not skip it. OFC solved all 22 degrees of freedom (DOF) from those two corners. The
proportional-only PID controller then applied 0.3 of that state, and the clip did not
limit it, because the clip acts only on the integral term.

Notebook: `notebooks/mtaos_visit_step_v1.ipynb`. Run output:
`output/20261109_visit_20261108_00468/` (PDF, summary and 22-DOF CSVs). Code:
`code/byvisit.py`. Sources are the Engineering Facility Database (EFD) and the
Consolidated Database (ConsDB). The reproduction uses the summit's ts_ofc v4.8.1 and the
v13 MTAOS configuration from ts_config_mttcs v0.22.12.

## MTAOS skip logic

Code: ts_mtaos tag v0.30.0-alpha.5 (commit d12f57b), `python/lsst/ts/mtaos/model.py`
and `wavefront_collection.py`. Configuration: ts_config_mttcs v0.22.12 `MTAOS/v13/_init.yaml`,
with `num_expected_tables: 4`, `num_expected_tables_min: 4`,
`zernike_column_pattern: deviation_columns`.

1. `_poll_butler_outputs` (model.py:1344) queries the Butler `zernikes` datasets for the
   visit. It keeps each table with `len(table) > 0` and raises
   `NotEnoughWaveFrontDataError` only if fewer than `num_expected_tables_min` (4) tables
   remain. That check produces the log line "Found 4 non-empty tables out of 4 total
   tables". On seq 466, WEP wrote a table for every corner, so all 4 passed.
2. `WavefrontCollection.pop` (wavefront_collection.py) takes the row labelled `average` in
   each table and reads its deviation columns. On corners 191 and 195 those values are
   NaN, but they are kept.
3. `get_sensor_ids_wfe_from_data_container` builds `wfe` with one row per sensor, and
   there is no NaN filter here either.
4. `calculate_corrections` (model.py:1510) logs `f"{wfe.shape[0]}/4 wavefront error
   measurements were found. If fewer than 3 are found, this image will be skipped."`
   This is only a message: no comparison with 3 exists in this path. It then calls
   `_calculate_corrections`, which passes all 4 rows to OFC.
5. ts_ofc `ofc.py` then drops the NaN rows and solves from the 2 finite corners.

The only effective minimum is therefore 4 non-empty tables. A table whose average row
is NaN counts as a measurement. The same code appears at ts_mtaos v0.30.0 and on
`main` as of 2026-09-02; neither contains `isnan`, `isfinite` or a comparison with 3.
