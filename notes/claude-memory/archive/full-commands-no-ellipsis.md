When giving Aaron a command, include the FULL command with **no `...`,
placeholders, or abbreviations** (e.g. spell out the entire seq_num list, the
full collection name), so he can cut and paste it directly.

**Why:** he runs them by copy-paste; any ellipsis or `<placeholder>` forces
manual editing and is error-prone.

**How to apply:** expand every list/argument in full. If a value is genuinely
unknown, ask for it rather than leaving `...`. Pairs with [[gitpull-script]].
