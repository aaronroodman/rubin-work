# Claude memory snapshot (handoff)

Snapshot of Claude Code auto-memory for the OptAtmo project, checked in here so it
can be handed off between Claude accounts/machines.

**To load on another account:** copy these files into that account's memory dir
(`~/.claude/projects/<project-slug>/memory/`). `MEMORY.md` is the index that Claude
loads each session; `optatmo-moments-project.md` is the full project memory.

The live source of truth on Aaron's laptop is
`~/.claude/projects/-Users-roodman-Astrophysics-Claude/memory/`; re-copy from there
when updating this snapshot.
